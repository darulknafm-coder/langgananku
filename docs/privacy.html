Kebijakan Privasi LanggananKu

Berlaku sejak: 18 Oktober 2026

LanggananKu adalah aplikasi untuk mencatat dan memantau langganan berbayar. Kebijakan ini menjelaskan data apa yang diproses aplikasi dan bagaimana data itu diperlakukan.

Ringkasan

  • LanggananKu tidak mengumpulkan, mengirim, atau menjual data pribadi Anda.
  • Tidak ada akun, tidak ada server, tidak ada iklan, dan tidak ada pelacak/analitik pihak ketiga.
  • Semua data disimpan di perangkat Anda dan terhapus bila aplikasi dihapus.

Data yang diproses di perangkat

  • Data langganan yang Anda masukkan: nama layanan, nominal, siklus tagihan, tanggal jatuh tempo, metode pembayaran, dan catatan. Disimpan di penyimpanan lokal aplikasi.
  • SMS (khusus Android, bila fitur pindai SMS tersedia dan Anda mengizinkan): aplikasi membaca SMS kotak masuk untuk menemukan notifikasi transaksi langganan dari bank atau e-wallet. Pemindaian dilakukan sepenuhnya di perangkat. Isi SMS tidak disimpan dan tidak dikirim ke mana pun; yang disimpan hanya hasilnya (nama layanan, nominal, tanggal) setelah Anda menyetujuinya.
  • Anggota patungan (opsional): nama dan nomor WhatsApp yang Anda isi sendiri, dipakai untuk membuka WhatsApp dengan pesan pengingat. Disimpan hanya di perangkat; pesan dikirim oleh Anda sendiri melalui WhatsApp.
  • Kunci aplikasi (opsional): PIN disimpan di perangkat dalam bentuk hash, bukan angka aslinya. Sidik jari/Face ID diperiksa oleh sistem operasi; aplikasi tidak pernah menerima data biometrik Anda.
  • Teks yang Anda tempel (email nota, struk): dianalisis di perangkat dengan cara yang sama dan tidak dikirim ke mana pun.

Koneksi internet

Aplikasi memakai internet hanya untuk dua hal, dan keduanya tidak mengirim data pribadi atau data langganan Anda:

  • Logo layanan: ikon resmi layanan di katalog (mis. netflix.com) diunduh melalui layanan ikon situs milik Google, dengan mengirim nama domain layanan tersebut. Logo disimpan di perangkat sehingga hanya diunduh sekali. Fitur ini bisa dimatikan di Setelan → Tampilkan logo layanan.
  • Data paket & promo: daftar harga paket dibaca dari file publik di situs ini (darulknafm-coder.github.io), yang di-hosting oleh GitHub.

Seperti semua koneksi internet, penyedia tersebut (Google dan GitHub) dapat menerima alamat IP perangkat Anda sesuai kebijakan privasi mereka.

Notifikasi

Pengingat jatuh tempo dijadwalkan secara lokal di perangkat. Tidak ada layanan notifikasi server yang dipakai.

Tautan ke layanan lain

Tombol "Batalkan langganan" membuka halaman resmi layanan terkait (mis. Netflix atau Google Play) di browser. Aktivitas Anda di situs tersebut tunduk pada kebijakan privasi masing-masing.

Cadangan data

Fitur cadangan menyimpan data Anda sebagai file di lokasi yang Anda pilih (mis. folder Download atau Google Drive), atau menyalinnya ke clipboard. Aplikasi tidak mengunggah file itu ke mana pun; ke mana file disimpan sepenuhnya keputusan Anda.

Penghapusan data

Anda dapat menghapus semua data kapan saja melalui Setelan → Hapus semua data, atau dengan menghapus aplikasi.

Anak-anak

Aplikasi ini ditujukan untuk pengguna dewasa (18+) dan tidak ditujukan untuk anak-anak.

Perubahan kebijakan

Bila kebijakan ini berubah (misalnya saat fitur sinkronisasi atau akun ditambahkan), versi terbaru akan dipublikasikan di halaman ini beserta tanggal berlakunya.

Privacy Policy (English summary)

LanggananKu does not collect, transmit, sell, or share any personal data. There are no accounts, servers, ads, or third-party analytics. Subscription data you enter is stored only on your device. On Android, if you grant SMS access, inbox messages are scanned on the device to detect subscription charges; message content is never stored or sent anywhere. Pasted receipt text is processed on the device the same way. Reminders are scheduled locally. The app uses the internet only to download service logos (by sending the service's domain name to Google's site-icon service; can be turned off in Settings) and to read the public price/promo list from this website (hosted by GitHub); no personal or subscription data is sent. You can delete all data in Settings or by uninstalling the app. Contact: langgananku.app@gmail.com
